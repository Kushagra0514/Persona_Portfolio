# Portfolio direction

Audience: software engineering / AI internship recruiters and open-source collaborators.

Palette: paper #F7F8F4, ink #202B25, forest #315640, muted #5F6961, sage #E5EBDF, line #D4DBD0. No gradients.

Type: Newsreader for expressive editorial headlines; Archivo for navigation, body, and project details. Self-hosted fonts. Body copy stays within 70 characters per line.

Layout: left-aligned introduction with a quiet portrait on the right; a wide Studio feature followed by two equal project features; spacious about and contact sections.

    name                      work / about / contact / resume
    large statement                       portrait
    introduction + calls to action        name / location
    selected work                         GitHub
    Studio explanation       retrieval architecture diagram
    UniFlow diagram          LocalFlow diagram
    about / education        skills
    contact invitation       email / social links

Review: rejected the skill's initial developer-tool dark theme and the retry's blue accent / brutalist styling because they conflict with the user's light editorial brief. Retained strong hierarchy, readable static content, and portfolio typography guidance. Forest green ties to the landscape in the supplied portrait. Project visuals explain actual architecture rather than imitate nonexistent screenshots. No invented roles, dates, testimonials, or live demos.

The homepage should read in under a minute; case studies carry technical detail. The resume remains independent. Motion is limited to interaction feedback, with reduced-motion support.
